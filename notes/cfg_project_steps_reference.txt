STEP 2 — Markov model baseline (sequence-only) with evaluation
Goal:
• Use hg38 DNA sequence for each 200 bp bin
• Train separate Markov models for Bound (B) vs Unbound (U)
• Score bins using log-likelihood ratio (LLR)
• Evaluate with k-fold cross-validation (ROC/PR curves, AUCs)
• Sweep Markov order m=0..10 to pick best

--------------------------------------------------------------------------------
STEP 2.1 — Download hg38 FASTA and place in data/genome/
Commands used (UCSC recommended):
mkdir -p data/genome
cd data/genome
wget -O hg38.fa.gz https://hgdownload.cse.ucsc.edu/goldenpath/hg38/bigZips/hg38.fa.gz
gunzip -f hg38.fa.gz

Verification:
ls -lh data/genome
head -n 10 data/genome/hg38.fa
Expected:
• >chr1 header is present
• Initial N blocks are normal

--------------------------------------------------------------------------------
STEP 2.2 — Index FASTA and fetch 200 bp sequence for one bin
Install and index:
pip install pysam
python -c "import pysam; pysam.faidx('data/genome/hg38.fa')"

Verify:
head -n 3 data/genome/hg38.fa.fai

Test sequence fetch script: src/fetch_one_bin.py
Logic:
• read chr1 TSV row
• pysam.FastaFile(hg38).fetch(chr, start, end).upper()
• print length (should be 200) and whether it contains N

--------------------------------------------------------------------------------
STEP 2.3 — Markov model core + single-fold test
Files created:
• src/markov_core.py
  - train_markov(seqs, m): Laplace-smoothed context→next-base probabilities
  - log_prob_seq(model, seq, m): log-likelihood with fallback uniform for unseen contexts
  - llr_score(pos_model, neg_model, seq, m): logP_pos - logP_neg

• src/markov_single_fold_test.py
  - loads chr1 labeled bins
  - fetches sequences from hg38
  - splits into B vs U for a TF (CTCF)
  - trains pos/neg models
  - prints sample LLR scores for B and U bins

Example run:
python src/markov_single_fold_test.py

--------------------------------------------------------------------------------
STEP 2.6 — Evaluate other TFs (REST, EP300) with chosen m
File:
• src/markov_cv_one_tf.py
Outputs:
• results/markov_tf_runs/*_roc_fold*.png, *_pr_fold*.png (per TF)

================================================================================
STEP 3 — Train on all labeled chromosomes and predict unknown chr3/chr10/chr17
Goal:
• Train pos/neg Markov models on ALL labeled chromosomes (data/train/*.tsv)
• Predict labels for unknown bins in data/unknown/chr3/chr10/chr17
• Output per chromosome per TF: score + predicted label (threshold 0.0)

File:
• src/markov_train_predict.py

Run (per TF):
python src/markov_train_predict.py --hg38 data/genome/hg38.fa --tf CTCF  --m 6
python src/markov_train_predict.py --hg38 data/genome/hg38.fa --tf REST  --m 6
python src/markov_train_predict.py --hg38 data/genome/hg38.fa --tf EP300 --m 6

Outputs:
• results/markov_predictions/chr3_CTCF_pred.tsv (and similarly for chr10/chr17 and REST/EP300)
Columns:
chr  start  end  TF  score  pred
